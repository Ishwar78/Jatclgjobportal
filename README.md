# AIJHM College Recruitment Portal Frontend

## Run
```bash
npm install
npm run dev
```

- React + Vite
- React Router DOM
- React Icons
- Montserrat, sans-serif
- Dedicated JSX and CSS files for public/auth/application/user/admin pages
- Mock frontend validation and navigation flow
- No data.js file; page content is kept inside page files
- Admin pages are inside `src/pages/admin`
- User pages are inside `src/pages/user`
